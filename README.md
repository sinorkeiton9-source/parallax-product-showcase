# Parallax — Product Showcase

Parallax is a proprietary Windows desktop workspace for development projects. It brings project organization, terminals, code editing, Git work, and AI coding tools together in one place.

[Visit the Parallax website](https://parallaxhq.dev)

## Product

Parallax is built and maintained by Keiton Sinor. The product is designed to help developers keep project context and everyday development work together as they move between projects.
